# Chapters

Store one chapter per file using TEMPLATES/CHAPTER.md. Keep working drafts separate from author-approved text when a chapter undergoes substantial revision.

Suggested naming: `001-title.md`, `002-title.md`.

A chapter marked author-approved is authoritative for events that occur on-page, but proposed interpretations and unapproved additions remain non-canon. After approval, reconcile consequential events into CANON/CHRONOLOGY.md, CANON/STATE.md, CANON/KNOWLEDGE.md, CANON/RELATIONSHIPS.md, and CANON/OPEN_THREADS.md as applicable.

Do not overwrite an approved chapter silently. Preserve a clear revision history through Git commits.
