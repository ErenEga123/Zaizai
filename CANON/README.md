# Canon index

This directory contains only author-approved facts relevant to Kairon Voss and characters who have established interactions with him. Kairon is an original secondary character added to the existing story; this repository tracks his interactions without recasting him as the original protagonist.

## Scope rule

The tracked cast is dynamic. Add a character only when an approved source or explicit author statement establishes a direct or consequential interaction with Kairon. Do not create individual dossiers for unrelated characters, incidental mentions, or characters whose only interactions are with other people.

## Records

- [KAIRON_VOSS.md](CHARACTERS/KAIRON_VOSS.md) — author-approved dossier for Kairon Voss.
- CHARACTERS.md — Kairon and the dynamic interacting-cast index.
- WORLD.md — only setting rules needed to understand Kairon's interactions.
- CHRONOLOGY.md — events involving Kairon and tracked interaction participants.
- RELATIONSHIPS.md — relationship states and changes involving Kairon.
- KNOWLEDGE.md — knowledge and information provenance for Kairon and interacting characters.
- STATE.md — relevant physical, logistical, and organizational state.
- OPEN_THREADS.md — unresolved threads affecting Kairon or his interactions.

Only the author can approve additions, corrections, or retcons. Assistant suggestions belong in WORK/PROPOSED_CANON_CHANGES.md. Every important fact must be traceable to approved material. Mark uncertainty instead of filling gaps.
