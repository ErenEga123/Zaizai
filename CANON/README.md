# Canon index

This directory contains only author-approved story facts. No story canon is pre-populated.

## Records
- WORLD.md — setting rules, geography, technology, institutions, terminology.
- CHARACTERS.md — character index and links to individual dossiers.
- CHRONOLOGY.md — dated events and ordering constraints.
- RELATIONSHIPS.md — relationship states and changes.
- KNOWLEDGE.md — character-specific knowledge, beliefs, secrets, and information provenance.
- STATE.md — current physical, logistical, political, and organizational state.
- OPEN_THREADS.md — unresolved plot lines, promises, mysteries, and intended payoffs.

Only the author can approve additions, corrections, or retcons. Assistant suggestions belong in WORK/PROPOSED_CANON_CHANGES.md. Every important fact should be traceable to an author instruction, approved chapter, or explicit author decision. Mark uncertainty instead of filling gaps.
