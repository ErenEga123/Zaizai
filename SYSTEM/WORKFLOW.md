# Standard Writing Workflow

## Stage 0 — Intake
Classify the request and define its scope. Identify whether the task concerns Kairen directly, a scene involving an already tracked character, or a possible new interaction that may expand the tracked cast.

## Stage 1 — Context retrieval
Archivist reads global rules and the smallest sufficient set of approved canon, state, and manuscript records. Always load Kairen's current state. Load only the tracked characters relevant to this task and the adjacent events needed for continuity.

## Stage 2 — Interaction-scope check
Interaction Mapper checks whether any character in the source material has an established direct or consequential interaction with Kairen. If yes and not yet tracked, create a PROPOSED inclusion entry with evidence. Do not create a dossier for unrelated characters. If the interaction is ambiguous, mark UNKNOWN and ask only if it affects the task.

## Stage 3 — Preflight
Continuity Analyst checks timeline, location, availability, physical condition, equipment, resources, relationships, active threads, and consequences. Knowledge Auditor checks information boundaries for Kairen and each interacting character.

## Stage 4 — Planning
Planner defines scene purpose, POV, entry state, beats, conflict, turn, exit state, and causal links. All new facts remain proposals.

## Stage 5 — Drafting
Writer follows the approved brief and plan. Preserve requested scope. Do not summarize when prose was requested. Do not resolve open threads or add unapproved interactions.

## Stage 6 — Independent audits
Canon Auditor checks facts and state. Knowledge Auditor checks who knows what and when. Developmental Editor checks motivation, pacing, voice, repetition, and readability.

## Stage 7 — Revision and delivery
Supervisor consolidates findings by severity. Writer revises blockers and major defects. Return the complete requested text first, then a concise audit summary and unresolved author decisions.

## Stage 8 — State proposal
Propose event and state deltas only for Kairen and characters who interact with him. Include timeline, location, condition, equipment, knowledge, relationship, resources, and open-thread effects where relevant. Mark all as PROPOSED.

## Stage 9 — Author approval
No canon, tracked-cast register, or state update is authoritative until the author explicitly approves it. Silence and generated prose are not approval.

## Stage 10 — Commit
After approval, update only relevant records. Inspect the diff for scope creep, duplicates, contradictions, and accidental dossiers for unrelated characters. Commit with a descriptive message and report the actual result.
